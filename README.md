A thrilling time-traveling game where you pilot a DeLorean through temporal anomalies! Test your reflexes as you navigate through colorful time portals in this endless runner-style game.

🔗 **Play the game here:** [https://danielgaudreault.github.io/DeloreanTimetravelChallenge/](https://danielgaudreault.github.io/DeloreanTimetravelChallenge/)

## Game Concept
You're Marty McFly trying to keep the DeLorean in the time stream! Avoid colliding with the temporal anomalies (colorful poles) while traveling as far as possible through time.

## Features
- **Retro 80s aesthetic** with DeLorean graphics
- **Increasing difficulty** - anomalies come faster as you progress
- **High score system** with local storage saving
- **Responsive design** works on desktop and mobile
- **Two control schemes**:
  - Hold SPACE key or on-screen button to ascend
  - Release to descend
- **Starfield background** for authentic time travel feel
- **Time portal obstacles** with vibrant colors

## How to Play
1. Press the **FLY button** (or SPACE key) to make the DeLorean ascend
2. Release to descend
3. Navigate through the gaps between the temporal anomalies
4. Try to stay in the time stream as long as possible!
5. Game ends when you collide with an anomaly
6. Press RESET to try again

## Technologies Used
